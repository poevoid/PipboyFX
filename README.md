This is a program intended to be loaded onto Arduboy and Arduboy-compatible game systems. It's supposed to mimic some basic functions of a Pipboy from the Fallout series. It has many features!
- Vault-boy splashscreen/Flashlight mode can be activated at any time in the main menu by pressing B, and the flashlight mode can be turned off again by pressing A while the splashcreen is visible.
- False inventory with some easter eggs if you look into the coordinates.
- USB screen to interface with computers
  * BadUSB attacks for windows and linux
    - Talker, makes a computer speak a creepy message.
    - Forkbomb, can crash most computers, be careful with this one.
    - Youtube roll, opens a video in web browser, in this case an NSP video but this can be easily changed in fxdata.txt
  * Game controller - basic usb game controller, good for gameboy games on retroarch and such.
  * Key Macros - just some basic key shortcuts for windows and linux.
  * Serial - Serial monitor, displays strings sent through serial.
  * Oscilloscope/Mic - A visualizer/data plotter for an optional electret microphone & preamp. You can select between pins A4 and A5 for the signal OUT of the mic's preamp. 
- Map screen displays a basic pixel-art version of three maps, selected with up and down buttons.
  * Houston
  * Portland
  * Los Angeles
- RAD screen is a false radio, showing a waveform on the right, and giving the user three options of songs to play.
  Currently you may choose between three chiptunes of classic songs found in the fallout series:
  * Ain't that a kick (in the head)
  * Anything Goes
  * Johnny Guitar
